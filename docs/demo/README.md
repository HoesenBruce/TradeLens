# Generated demo trade data

`tradermemos-demo-trades.json` is independently generated by
`scripts/generate-financial-fixtures.py`, reusing `build_book` from
`scripts/seed-demo.py` with seed **210** and a fixed **2031-02-28 UTC** end date.
It includes stock/option long/short trades plus an invented partial-close open
position. No broker exports or account records are read. It has no account
identity or cash transactions; choose a generated demo account when importing.

Regenerate and verify all public samples:

```sh
python3 scripts/generate-financial-fixtures.py
python3 scripts/generate-financial-fixtures.py --check
```

For screenshots dated near today, use `scripts/seed-demo.py --seed 210
--end-date YYYY-MM-DD` against a fresh throwaway API. The seed and end date
must be recorded with the capture. Dates and prices are illustrations, not
market data, trading recommendations or real performance.
