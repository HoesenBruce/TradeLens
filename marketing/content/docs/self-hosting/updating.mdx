---
title: Updating
description: Update TradeLens from source and preserve its database migration chain.
---

> **Current TradeLens status:** official TradeLens images are not yet published. Docker image publishing and Release Please are disabled. Use `make up-build` (SQLite) or `make up-postgres-build` (PostgreSQL) to build this checkout.
>
> **Database boundary:** `make up` and `make up-postgres` currently pull upstream TraderMemos images (`sinhong2011/tradermemos-*`) by default. Upstream and TradeLens migration histories have diverged. Never alternate them against the same existing database volume, including PostgreSQL. Use a separate Compose project and fresh database/volumes for a different product; retain a complete backup before any migration.

Back up the complete instance before every upgrade. Migrations run automatically on API startup; there is no automatic downgrade. Restore the pre-upgrade database and attachments with the matching source revision for rollback. [→ Backup & restore](/en/docs/self-hosting/backup-restore)

## Source updates (current TradeLens path)

Keep the existing checkout, Compose project name, `.env` and volumes. Review the target revision and changes before updating. Use the SQLite command or the PostgreSQL command matching your existing installation; do not run both against the same database.

```bash
git pull --ff-only
make up-build           # SQLite
# OR: existing PostgreSQL installation
make up-postgres-build
```

Verify the running version with `curl -fsS http://localhost:3000/healthz`. For repeatable source builds, record the Git commit; `TM_IMAGE_TAG` labels local builds but does not select the source revision.

## Prebuilt images (upstream or your own publisher)

Only for an existing installation using that same publisher and migration chain: pin its available tag in `.env` with `TM_IMAGE_TAG`, pull, then restart using its original Compose files. No official TradeLens tags or multi-architecture images are promised. Do not run this path on a TradeLens source installation.

## CDN / hosted API

Update from your chosen TradeLens revision. Deployment automation depends on your provider configuration; the fork’s Vercel release workflow is currently disabled. Preserve the API database and attachments volume. Syncing upstream code is not a substitute for reviewing migration compatibility.
