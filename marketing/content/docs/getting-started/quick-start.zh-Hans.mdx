> **TradeLens:** 官方 TradeLens GHCR 镜像已发布，`make up` / `make up-postgres` 默认使用它们。源码方案为 `make up-build` / `make up-postgres-build`。Docker 发布仍为手动禁用，Release Please 已启用，不代表镜像持续发布。
>
> **TradeLens / TraderMemos DB:** TradeLens 与上游 TraderMemos 数据库迁移已分叉。不要交替使用同一个数据库；不同产品使用独立项目及新数据库。同一 TradeLens 从源码部署切换到官方镜像时，先完整备份，再保留原项目、配置和卷。

运行官方 TradeLens Web/API 镜像：

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
cp .env.example .env  # review JWT secret and pin TM_IMAGE_TAG
make up    # http://localhost:3000
```

就这么简单。同源 `/api`，无需 CORS 配置，登录时的 **Server** 字段留空即可。首次访问会出现
**初始化向导**，用于创建你的 owner 账户 —— 接下来请看
[入门指引](/zh-Hans/docs/getting-started/first-steps)。

## 其他选项与生产环境提示

```bash
cp .env.example .env
make up           # SQLite
# OR, on a separate new installation:
make up-postgres  # PostgreSQL
```

生产环境请设置 `TM_JWT_SECRET=$(openssl rand -hex 32)`，并在前面加一层 TLS —— 详见
[部署](/zh-Hans/docs/self-hosting/deploy)与
[反向代理](/zh-Hans/docs/self-hosting/reverse-proxy)。全部服务端配置项参见
[配置参考](/zh-Hans/docs/self-hosting/configuration)。

## 本地开发

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
make setup && make dev   # API :8080 + web :5173
```

关于各项 make 目标、Vite+ 命令与项目结构，参见
[CONTRIBUTING.md](https://github.com/HoesenBruce/TradeLens/blob/main/CONTRIBUTING.md)。

### TradeLens 合成展示

使用展示指南中的全新临时 API、数据库及本地合成行情服务。此种子拒绝重复运行，不用于真实组合。四个待验证和两个不可用周期不属于已评分投资结果。

[Showcase / 合成展示](https://github.com/HoesenBruce/TradeLens/blob/main/docs/showcase-demo.md)

```bash
python3 scripts/seed-demo.py --mode showcase \
  --api http://127.0.0.1:8093/api/v1 \
  --email fictional@example.com --password fictional-showcase-password
```

可选旧 USD 数据：`--mode legacy`。上游演示不是 TradeLens 部署。
