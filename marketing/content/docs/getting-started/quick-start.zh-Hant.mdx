> **TradeLens:** 官方 TradeLens GHCR 映像已發佈，`make up` / `make up-postgres` 預設使用它們。原始碼方案為 `make up-build` / `make up-postgres-build`。Docker 發佈仍為手動停用，Release Please 已啟用，不代表映像持續發佈。
>
> **TradeLens / TraderMemos DB:** TradeLens 與上游 TraderMemos 資料庫遷移已分歧。不要交替使用同一資料庫；不同產品使用獨立專案及新資料庫。同一 TradeLens 從原始碼部署切換至官方映像時，先完整備份，再保留原專案、設定與卷。

執行官方 TradeLens Web/API 映像：

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
cp .env.example .env  # review JWT secret and pin TM_IMAGE_TAG
make up    # http://localhost:3000
```

就這麼簡單。同源 `/api`，無需 CORS 配置，登錄時的 **Server** 字段留空即可。首次訪問會出現
**初始化嚮導**，用於創建你的 owner 賬戶 —— 接下來請看
[入門指引](/zh-Hant/docs/getting-started/first-steps)。

## 其他選項與生產環境提示

```bash
cp .env.example .env
make up           # SQLite
# OR, on a separate new installation:
make up-postgres  # PostgreSQL
```

生產環境請設置 `TM_JWT_SECRET=$(openssl rand -hex 32)`，並在前面加一層 TLS —— 詳見
[部署](/zh-Hant/docs/self-hosting/deploy)與
[反向代理](/zh-Hant/docs/self-hosting/reverse-proxy)。全部服務端配置項參見
[配置參考](/zh-Hant/docs/self-hosting/configuration)。

## 本地開發

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
make setup && make dev   # API :8080 + web :5173
```

關於各項 make 目標、Vite+ 命令與項目結構，參見
[CONTRIBUTING.md](https://github.com/HoesenBruce/TradeLens/blob/main/CONTRIBUTING.md)。

### TradeLens 合成展示

使用展示指南中的全新暫存 API、資料庫及本機合成行情服務。此種子拒絕重複執行，不用於真實組合。四個待驗證和兩個不可用期間並非已評分投資結果。

[Showcase / 合成展示](https://github.com/HoesenBruce/TradeLens/blob/main/docs/showcase-demo.md)

```bash
python3 scripts/seed-demo.py --mode showcase \
  --api http://127.0.0.1:8093/api/v1 \
  --email fictional@example.com --password fictional-showcase-password
```

選用舊 USD 資料：`--mode legacy`。上游示範並非 TradeLens 部署。
