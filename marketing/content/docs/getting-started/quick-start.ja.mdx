> **TradeLens:** 公式 TradeLens GHCR イメージは公開済みで、`make up` / `make up-postgres` が使用します。ソース構築は `make up-build` / `make up-postgres-build`。Docker 公開は手動停止中、Release Please は有効です。継続イメージ公開は保証しません。
>
> **TradeLens / TraderMemos DB:** 上流 TraderMemos と TradeLens のマイグレーション履歴は分岐しています。同じデータベースを交互に使用しないでください。別の Compose プロジェクトと新規 DB を使います。同一 TradeLens のソース構築から公式イメージへの切替では、完全なバックアップを作成し、プロジェクト・設定・ボリュームを保持してください。

公式 TradeLens Web/API イメージを実行します：

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
cp .env.example .env  # review JWT secret and pin TM_IMAGE_TAG
make up    # http://localhost:3000
```

これだけです。`/api` は同一オリジンなので CORS は不要で、**サーバー**欄は空のままにしてください。
初回アクセス時には**セットアップウィザード**がオーナーアカウントを作成します。その後は
[最初の一歩](/ja/docs/getting-started/first-steps)へ進んでください。

## オプションと本番運用時の注意

```bash
cp .env.example .env
make up           # SQLite
# OR, on a separate new installation:
make up-postgres  # PostgreSQL
```

本番環境では `TM_JWT_SECRET=$(openssl rand -hex 32)` を設定し、前段に TLS を置いてください。
詳しくは[デプロイ](/ja/docs/self-hosting/deploy)と
[リバースプロキシ](/ja/docs/self-hosting/reverse-proxy)を参照してください。サーバー設定の一覧は
[設定リファレンス](/ja/docs/self-hosting/configuration)にあります。

## ローカル開発

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
make setup && make dev   # API :8080 + web :5173
```

ターゲット、Vite+ コマンド、プロジェクト構成については
[CONTRIBUTING.md](https://github.com/HoesenBruce/TradeLens/blob/main/CONTRIBUTING.md)
を参照してください。

### TradeLens 合成展示

展示ガイドの新規一時 API・DB とローカル合成プロバイダーを使用してください。再実行は拒否され、実際の口座用ではありません。待機4件・利用不可2件は採点済み投資結果ではありません。

[Showcase / 合成展示](https://github.com/HoesenBruce/TradeLens/blob/main/docs/showcase-demo.md)

```bash
python3 scripts/seed-demo.py --mode showcase \
  --api http://127.0.0.1:8093/api/v1 \
  --email fictional@example.com --password fictional-showcase-password
```

任意の旧 USD データ: `--mode legacy`。上流デモは TradeLens のデプロイではありません。
