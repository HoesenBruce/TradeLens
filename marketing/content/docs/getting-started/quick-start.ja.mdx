> **TradeLens の現状：** 公式 TradeLens イメージはまだ公開されていません。Docker イメージ公開と Release Please は無効です。ソースから `make up-build`（SQLite）または `make up-postgres-build`（PostgreSQL）でビルドしてください。
>
> **データベースの境界：**`make up` と `make up-postgres` は現在、既定で上流 TraderMemos イメージ（`sinhong2011/tradermemos-*`）を取得します。上流と TradeLens のマイグレーション履歴は分岐しています。同じ既存データベースボリュームに両製品を交互に接続しないでください（PostgreSQL も同様）。別製品には別の Compose プロジェクトと新規データベース／ボリュームを使い、移行前に完全なバックアップを保存してください。

このソースから TradeLens Web UI と API をビルドします：

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
make up-build    # http://localhost:3000
```

これだけです。`/api` は同一オリジンなので CORS は不要で、**サーバー**欄は空のままにしてください。
初回アクセス時には**セットアップウィザード**がオーナーアカウントを作成します。その後は
[最初の一歩](/ja/docs/getting-started/first-steps)へ進んでください。

## オプションと本番運用時の注意

```bash
cp .env.example .env
make up-build           # SQLite
# OR, on a separate new installation:
make up-postgres-build  # PostgreSQL
```

本番環境では `TM_JWT_SECRET=$(openssl rand -hex 32)` を設定し、前段に TLS を置いてください。
詳しくは[デプロイ](/ja/docs/self-hosting/deploy)と
[リバースプロキシ](/ja/docs/self-hosting/reverse-proxy)を参照してください。サーバー設定の一覧は
[設定リファレンス](/ja/docs/self-hosting/configuration)にあります。

## ローカル開発

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
make setup && make dev   # API :8080 + web :5173
```

ターゲット、Vite+ コマンド、プロジェクト構成については
[CONTRIBUTING.md](https://github.com/sinhong2011/TraderMemos/blob/main/CONTRIBUTING.md)
を参照してください。

### デモデータ

任意のインスタンスに、直近 3 か月分の生成トレード約 200 件を投入します。

```bash
make demo-seed API=http://localhost:3000/api/v1 EMAIL=you@example.com PASSWORD='…'
```

公開 API のみを使うため、ローカルスタックでもデプロイ済みのデモ環境でも動作します。
再実行しても何も起きません — 約定はサーバー側で重複排除されるためです。
