> **Current TradeLens status:** official TradeLens GHCR images are published. `make up` (SQLite) and `make up-postgres` (PostgreSQL) use them by default. Source-build fallback remains available through `make up-build` / `make up-postgres-build`. Docker publishing remains `disabled_manually`; Release Please is enabled. Image availability does not imply continuous publishing.
>
> **Database boundary:** TradeLens and upstream TraderMemos migration histories have diverged. Never hand a database used by one product to the other, including PostgreSQL. Use separate projects and fresh databases for different products. Switching an existing TradeLens source deployment to official TradeLens images is a same-product deployment change: take a complete backup, then preserve the checkout, Compose project, configuration and volumes.

Run the official TradeLens Web UI and API images:

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
cp .env.example .env   # review JWT secret and pin TM_IMAGE_TAG
make up          # http://localhost:3000
```

That's it. Same-origin `/api` — no CORS, leave the **Server** field blank. On first visit the
**setup wizard** creates your owner account — then head to
[First steps](/en/docs/getting-started/first-steps).

## Options and production notes

```bash
cp .env.example .env
make up                 # SQLite
# OR, on a separate new installation:
make up-postgres        # PostgreSQL
```

For production, set `TM_JWT_SECRET=$(openssl rand -hex 32)` and put TLS in front — see
[Deploy](/en/docs/self-hosting/deploy) and
[Reverse proxy](/en/docs/self-hosting/reverse-proxy). All server settings are in the
[Configuration reference](/en/docs/self-hosting/configuration).

## Local development

```bash
git clone https://github.com/HoesenBruce/TradeLens.git
cd TradeLens
make setup && make dev   # API :8080 + web :5173
```

See [CONTRIBUTING.md](https://github.com/HoesenBruce/TradeLens/blob/main/CONTRIBUTING.md) for
targets, Vite+ commands, and project structure.

### Synthetic TradeLens showcase

Use a new disposable API/database and the local synthetic provider from the showcase guide. This seed refuses reruns and is not for real portfolios. Four pending and two unavailable horizons are not scored investment results.

[Showcase / 合成展示](https://github.com/HoesenBruce/TradeLens/blob/main/docs/showcase-demo.md)

```bash
python3 scripts/seed-demo.py --mode showcase \
  --api http://127.0.0.1:8093/api/v1 \
  --email fictional@example.com --password fictional-showcase-password
```

Optional legacy USD data: `--mode legacy`. The upstream demo is not a TradeLens deployment.
